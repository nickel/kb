Plan: keep personal-loan instalments whole kronor after origination

Goal. Origination now refuses non-whole schedules, but servicing can still rewrite them into öre. The fix is in two parts: correct the rate reset now, and put the other three schedule-changing operations to Product, because whether the rule covers them is a business call.

Part 1: Rate reset (code, one PR)

The cause, read in packs/lending/servicing/app/public/queries/rate_reset_schedule.rb. The instalment that spans the reset date has its interest computed in straddle_interest (:71) and rounded to the öre. Its amount stays the old whole-krona amount, so its principal (amount minus interest) carries öre. The remaining balance handed to RepaymentScheduleBuilder then carries öre too, and the rebuilt final instalment ends in öre. The builder itself already gets the loan's installment_amount_policy, so the regular rebuilt instalments are fine.

1. Round the spanning instalment's interest by the loan's policy.
   - In straddle_interest, replace .round with Product::Pricing::RepaymentScheduleBuilder::Rounding.for(loan.installment_amount_policy).interest(...).
   - That rounds to the nearest krona under whole_unit_residual_final and keeps the öre rounding for every other policy, so existing loans don't change.
   - It's the same helper origination uses, so there's one rounding rule.
2. Refuse a reset that would still leave öre.
   - After the plan is built, run the same whole-unit check origination uses on the spanning instalment and the rebuilt lines.
   - If any instalment isn't whole, return Failure(:whole_unit_installments_violated).
   - ResetLoanRateOperation passes the failure through, as it does today for :schedule_dates_irregular. That needs one @failure tag line, which I'll ask you to approve.
3. Specs in rate_reset_schedule_spec.rb and the reset operation spec:
   - whole-krona loan, reset mid-period: the spanning instalment and every rebuilt instalment are whole, and the balance closes at zero;
   - reset on a period boundary (no spanning instalment): still whole;
   - a residual_final loan: same figures as before (regression);
   - a forced öre case: the reset is refused.
4. Docs. Add a line to "Whole-krona instalments" in docs/personal-loan-mechanics.md saying a rate reset keeps the rule. Check whether rate_reset_eir.rb (the IFRS 9 rate re-solve) assumes öre interest anywhere; I expect not, since it reads the stored amounts.
5. Verify.
   - targeted specs, then bin/check;
   - run the seed's rate-reset story on a personal loan (SEED_ENTITIES=cmc_sweden_ab SEED_VOLUME=1) and check its instalments after the reset with bin/rails runner;
   - /dual-review, scoped to this PR plus the unreviewed origination guard (956fe214c), so both are reviewed together.
